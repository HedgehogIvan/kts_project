# Игровой чат-бот "100 к 1"
## Описание:
Бот предназначен для реализации вариации игры "100 к 1" в группах телеграмма. 
Игра доступна для 4 человек.
## Правила игры:
Игра предназначена для 4 человек.
Игрокам предлагается угадать варианты ответов на какой-либо вопрос. 
Игрок, знающий ответ, должен как можно быстрее нажать на кнопку.
За правильные ответы игрокам начисляются очки. Если игрок не угадывает правильный ответ, он выбывает.
Игра заканчивается, если игроки либо угадали все ответы либо вылетели. 
Победителем признается игрок с наибольшим кол-ом очков.
## Установка и подготовка:
### Общее:
- Для использования этого проекта вам необходим python версии 3.10
- После клонирования репозитория необходимо настроить виртуальное окружение
- Установить зависимости
### БД:
- Вам необходимо проставить себе Postgres
- Подключить проект к Postgres
- Применить в терминале команду `alembic upgrade head`
- Изменить строку `sqlalchemy.url = postgresql+asyncpg://<bd_login>:<bd_pass>@localhost:5432/<bd_name>` в файле **alembic.ini** на ваши значения
- Изменить строку `"postgresql+asyncpg://<bd_login>:<bd_pass>@localhost:5432/<bd_name>"` в файле **"app\store\database.py\database.py"** на ваши значения
- Добавить в таблицу "questions" - вопросы для игроков
- Добавить в таблицу "answers" - ответы на существующие вопросы
### Telegram
- Для использования бота нужно создать бота для Tg через "BotFather".
- Добавьте код от бота в файл `config.yaml`
- Добавьте бота в группу, в которой вы планируете его использовать
- Введите команду `/start` для вызова бота
